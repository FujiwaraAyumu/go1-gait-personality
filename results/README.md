# results/

Colab で生成された結果のうち、小さいファイルだけをここに置きます。

| ファイル | 内容 |
|---|---|
| `summary.md` | 性格ごとの指標（平均 ± 95%信頼区間）と、標準との比較 |
| `summary.csv` / `metrics.csv` | 同じ内容の表データ（エピソードごとの値は `metrics.csv`） |
| `tradeoff.png` | 移動コストと、速度の追従誤差・胴体の揺れのトレードオフ |
| `metrics.png` | 指標ごとの比較 |
| `training.png` | 学習曲線 |

コピー元は Google ドライブの `go1-gait-personality/runs/<PROFILE>/results/` です。
動画（`*.mp4`）やチェックポイントはサイズが大きいので、リポジトリには入れません。
