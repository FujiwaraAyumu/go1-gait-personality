## 1. 課題の概要と目的

- 何を作ったか（1〜2文）：四足ロボット Go1 に強化学習で歩き方を学習させ、報酬の重みだけを変えて「歩き方の性格」を作り分けた
- なぜ取り組んだか：同じロボットでも、用途（物を運ぶ・長く動く・段差を越える）によって望ましい歩き方は違う。それを「報酬の設計」で表現できるかを確かめたい
- 提出物：動画（YouTube URL）、コード（GitHub URL）

## 2. アイデアと工夫した点

- 性格 = 報酬の重みの組み合わせ、という見方（`styles.py` の表をそのまま載せる）
- 標準の方策を1回だけ学習し、各性格はそこからのファインチューニングにした（学習時間の短縮）
- 全性格に同じ指令スケジュールを与え、複数回の評価で平均と95%信頼区間を出した（見た目の印象ではなく数値で比較）
- 先行研究との違い：Walk These Ways（Margolis & Agrawal, CoRL 2022）は歩容パラメータを方策の入力にして1つの方策で切り替える。本作は報酬の重みと、その結果として生じるトレードオフ（効率・正確さ・安定性）の定量評価に焦点を当てた

## 3. 方法

- 環境：MuJoCo Playground `Go1JoystickFlatTerrain`（速度指令に追従する歩行タスク）
- 学習：PPO（Brax）、Playground の調整済みハイパーパラメータ。学習量（ステップ数）と使用 GPU を明記
- 性格ごとの報酬の変更点：表で示す
- 評価の指令：静止 2秒 → 前進 0.6 m/s 5秒 → 前進 1.2 m/s 5秒 → 前進しながら左旋回 4秒 → 左へ横歩き 4秒
- 指標の定義
  - 移動コスト（Cost of transport）= Σ|関節トルク × 関節角速度|·Δt ÷（全質量 × 重力加速度 × 移動距離）
  - 速度の追従誤差 = 指令速度と実際の速度（水平方向）の差の RMS
  - 胴体の揺れ = 胴体のロール・ピッチ方向の角速度の RMS
  - 胴体の上下動 = 胴体の高さの標準偏差
  - 足の高さ = 1歩ごとの足先の最高点の平均

## 5. 考察

- どの指標とどの指標がトレードオフになったか、なぜそうなったと考えられるか
- 狙いどおりにならなかった性格があれば、その原因の仮説（報酬が 0 で切り捨てられる仕様、学習量不足など）
- 限界：平地のみ、シミュレーションのみ、評価回数、学習の乱数による違い
